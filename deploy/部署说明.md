# 数字乡村平台 · 部署说明（不给源码，只给产物）

给别人用，**不需要源码**。只需要下面两个「编译后的产物」：

| 产物 | 路径 | 说明 |
|---|---|---|
| 后端 | `backend/target/village-os-backend-1.0.0-SNAPSHOT.jar` | 约 47MB，可执行 jar（内含所有依赖） |
| 前端 | `frontend/dist/` | 纯静态文件（HTML/JS/CSS，已压缩混淆） |

---

## 一、环境要求

- **运行后端**：JDK 17 或更高（17 / 19 / 21 / 25 均可），`java` 在 PATH 中即可
- **托管前端**：nginx（推荐），或任意能反代的静态服务器
- **浏览器**：Chrome / Edge 等现代浏览器

> 前端打包产物约 1MB 的 index.js + 若干 chunk，浏览器直接访问即可，无需 Node。

---

## 二、方式 A：你部署好，只给别人一个网址（最省事）

1. 启动后端（见「四、启动后端」）。
2. 用 nginx 托管 `frontend/dist` 并反代 `/api`（见「五、nginx 反代」）。
3. 把 `http://你的域名或IP` 发给别人，他们浏览器打开就能用，什么也不用装。

### 方式 B：把产物打包发给别人

1. 把 `backend/target/village-os-backend-1.0.0-SNAPSHOT.jar` 和 `frontend/dist/` 打成一个 zip 发过去。
2. 对方机器上：
   - 装 JDK 17+；
   - 双击 `start-backend.bat`（Windows）或 `./start-backend.sh`（Linux/macOS）启动后端；
   - 用 nginx（配置见 `nginx.conf`）托管 dist 并反代 `/api`；
   - 浏览器访问。

## 四、启动后端

**Windows**：双击 `deploy/start-backend.bat`

**Linux / macOS**：
```bash
chmod +x deploy/start-backend.sh
./deploy/start-backend.sh
```

**手动**：
```bash
cd backend
java -jar target/village-os-backend-1.0.0-SNAPSHOT.jar
```

启动成功标志：日志出现 `Started ... in X seconds`，监听 8080 端口。

---

## 五、nginx 反代

直接使用 `deploy/nginx.conf`，按文件顶部注释改两处：
1. `root` → 改成 `frontend/dist` 的绝对路径；
2. `server_name` → 改成你的域名或 IP。

核心规则：
- `/` → 静态文件 + SPA 回退到 `index.html`
- `/api/` → 反代到 `http://127.0.0.1:8080`
- `/ws/` → WebSocket 反代（可选）
- `/deepseek/` → AI 大模型代理（可选，需 API Key，默认注释）

## 八、常见问题

**Q：8080 端口被占用？**
改 `backend/src/main/resources/application.yml` 的 `server.port`，再重新打包；同时把 nginx 里 `proxy_pass` 的 8080 也改掉。

**Q：提示「不支持发行版本」/ Java 版本报错？**
说明打包用的 JDK 低于 17。换 JDK 17+ 再打包即可（本机若 `JAVA_HOME` 指向旧 JDK，把 `JAVA_HOME` 指向 JDK 17+ 或直接用 PATH 里的 java）。

**Q：页面能打开，但数据接口 404 / 打不开？**
检查 nginx 的 `/api/` 反代是否配好、后端是否在跑、是否改动了端口。

**Q：登录提示「用户名或密码错误」？**
农户用 `/login`（王友德/123456），管理员用 `/admin`（admin/admin123），两个入口分开，别搞混。

**Q：别人打开是白屏？**
多半是前端被放到子目录（如 `http://ip/village`）而非域名根目录。当前打包按根路径 `/` 生成资源，请部署在域名/IP 根目录。

## 九、重要提示（当前是演示样板）

1. **登录是演示账号**，没有真实多用户账号体系、密码都是明文示例。
2. **数据库是 H2 单机文件**，不是真正的多用户生产库（`pom.xml` 已预留 MySQL 依赖，可切换）。
3. **只有中堰村一个村**，多村/多租户尚未做。
4. 正式对外长期使用，建议补齐：真实账号权限、MySQL、HTTPS、国内域名备案。

> 「不给源码」指不交付源代码仓库、不让他改代码；但前端 JS（浏览器必需）和后端 `.class` 技术上仍可被反编译，无法做到 100% 加密。要更高保密需另做 JS 混淆 / 接口化改造。
