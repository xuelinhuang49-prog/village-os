## 三、需新建 / 补齐的接口清单（按重要性排序）

1. **图片 / 文件上传**（产品图、诉求照片、头像）——目前无
2. **消息通知**（审核结果、诉求回复推送村民）——目前驳回后村民需自己看，无提醒
3. **GIS 点位接口**（前端已调、后端缺，属"会报错"级别）
4. **电商订单 / 商品闭环**（✅ 商品+订单的列表与增删改已接真接口；订单仍是单商品简表，多商品明细/支付/退款/售后需扩展后端订单模型，溯源/直播/经营分析仍需新建）
5. **溯源 / 直播 / 经营分析**（后端需新建）
6. **病虫害 AI 诊断**（需接真实 AI 识别服务，替换随机模拟）
7. **培训报名 / 预约接口**（课程已有，报名/取消报名目前存本地 localStorage，需落库并按村民身份关联）

| 部署 | 本机 `mvn` 起服务 | 打包部署到服务器 + HTTPS |
