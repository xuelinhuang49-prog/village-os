# 数字乡村平台 - 部署说明

> 适用环境: Linux / Windows / macOS | 第一阶段: 开发环境部署

---

## 一、环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | 推荐 Eclipse Temurin 17 |
| Maven | 3.9+ | 构建后端 |
| Node.js | 18+ | 构建前端 |
| PostgreSQL | 15+ | 主数据库 |
| PostGIS | 3.x | 空间扩展（可选） |
| Redis | 7.x | 缓存服务 |

---

## 二、快速启动 (开发环境)

### 2.1 安装依赖

```bash
# macOS
brew install openjdk@17 maven node postgresql@15 redis

# Ubuntu/Debian
sudo apt install openjdk-17-jdk maven nodejs npm postgresql redis-server

# Windows
# 下载安装包: adoptium.net, nodejs.org, postgresql.org
```

### 2.2 初始化数据库

```bash
# 创建数据库
createdb -U postgres village_os

# 启用 PostGIS (可选)
psql -U postgres -d village_os -c "CREATE EXTENSION IF NOT EXISTS postgis;"

# 导入初始化脚本
cd village-os/sql
psql -U postgres -d village_os -f schema.sql
psql -U postgres -d village_os -f village.sql
psql -U postgres -d village_os -f gis.sql
psql -U postgres -d village_os -f iot.sql
psql -U postgres -d village_os -f event.sql

# 或一条命令
psql -U postgres -d village_os -f init.sql
```

### 2.3 启动 Redis

```bash
# macOS
brew services start redis

# Linux
sudo systemctl start redis-server

# Windows
redis-server
```

### 2.4 启动后端

```bash
cd village-os/backend
./mvnw spring-boot:run

# 或
mvn spring-boot:run

# 后端启动在: http://localhost:8080
# 健康检查: http://localhost:8080/actuator/health (如已配置)
```

### 2.5 启动前端

```bash
cd village-os/frontend
npm install
npm run dev

# 前端启动在: http://localhost:5173
```

### 2.6 验证

```bash
# 1. 测试登录
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 2. 测试村庄接口
curl -H "Authorization: Bearer <token>" \
  http://localhost:8080/api/v1/village/list

# 3. 测试GIS点位
curl -H "Authorization: Bearer <token>" \
  "http://localhost:8080/api/v1/gis/objects?village_id=1"

# 4. 测试WebSocket
# 浏览器控制台:
# const ws = new WebSocket('ws://localhost:8080/ws/iot')
# ws.onmessage = e => console.log(JSON.parse(e.data))
```

## 三、Docker 部署 (推荐)

### 3.1 docker-compose.yml

```yaml
version: '3.8'
services:
  postgres:
    image: postgis/postgis:15-3.3
    environment:
      POSTGRES_DB: village_os
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./sql:/docker-entrypoint-initdb.d

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  backend:
    build: ./backend
    ports:
      - "8080:8080"
    depends_on:
      - postgres
      - redis
    environment:
      SPRING_DATASOURCE_URL: jdbc:postgresql://postgres:5432/village_os
      SPRING_DATA_REDIS_HOST: redis

volumes:
  pgdata:
```

### 3.2 启动

```bash
cd village-os
docker-compose up -d
```

## 四、配置说明

### 后端配置 (application.yml)

```yaml
# 数据库
spring.datasource.url: jdbc:postgresql://localhost:5432/village_os
spring.datasource.username: postgres
spring.datasource.password: postgres

# Redis
spring.data.redis.host: localhost
spring.data.redis.port: 6379

# JWT
jwt.secret: <base64-encoded-256bit-key>
jwt.expiration: 86400000  # 24小时

# 初始化
spring.sql.init.mode: always   # 首次启动后改为 never
```

## 六、常见问题

### Q: PostGIS 扩展安装失败?
A: 不影响基本功能。geometry 字段自动使用 WKT 文本存储，地图点位仍可正常使用。

### Q: 端口被占用?
A: 修改 `application.yml` 中的 `server.port` 配置。

### Q: 数据库连接失败?
A: 确认 PostgreSQL 已启动，用户名密码正确，数据库 village_os 已创建。

### Q: BCrypt 密码验证失败?
A: 用 Java 代码重新生成 hash:
```java
System.out.println(new BCryptPasswordEncoder().encode("admin123"));
```
替换 `sql/village.sql` 中的 password 值。
