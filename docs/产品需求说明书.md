# 数字乡村平台 - 产品需求说明书 (PRD)

> 版本: v1.0 | 日期: 2026-06-30 | 状态: Sprint 1 进行中

---

## 一、产品定位

数字乡村平台（Village OS）是一套面向中国乡村数字化转型的 SaaS 平台。

**核心价值：** 一个平台管理村庄全部数字化业务 — GIS地图 · IoT监测 · 产业管理 · 资产运营 · 乡村治理 · AI决策

**目标客户：** 乡镇政府 / 村委会 / 农业产业园 / 乡村振兴项目

**商业模式：** SaaS订阅（按村庄 + 按模块付费）

---

## 二、用户角色

| 角色 | 权限范围 | 典型用户 |
|------|---------|---------|
| 超级管理员 | 全平台 | 平台运营方 |
| 乡镇管理员 | 本乡镇所有村庄 | 乡镇干部 |
| 村管理员 | 本村全部数据 | 村支书/村主任 |
| 网格员 | 本村指定模块 | 村干部 |
| 村民 | 查看公开信息 + 上报事件 | 村民 |

---

## 三、功能模块全景

### 🏠 驾驶舱
- 村庄概览（人口、面积、产业）
- IoT设备在线状态
- 事件处理统计
- 今日告警汇总
- 实时数据卡片

### 🗺️ GIS 数字孪生
- 村庄地图（Leaflet/MapTalks）
- 地标点位标记（10+ 类型）
- 图层管理（设备/事件/资产）
- 空间查询（PostGIS）
- 村庄边界展示

### 📡 IoT 实时监控
- 设备管理（增删改查）
- 实时数据 WebSocket 推送
- 历史数据图表
- 告警规则配置
- 设备状态监控

### 🏭 产业管理
- 农业产业园管理
- 大棚种植管理
- 水产养殖管理
- 农产品溯源
- 产量统计

### 🏢 资产运营
- 资产台账（房屋/设备/土地）
- 资产租赁管理
- 合同管理
- 收入统计
- 资产维护

### 🏛️ 乡村治理
- 事件上报/派发/处理/闭环
- 网格管理
- 通知公告
- 党建管理
- 村务公开

### 🤖 AI 智能分析
- 产量预测
- 病虫害识别
- 价格趋势分析
- 异常检测
- 智能问答

---

## 四、非功能需求

| 需求 | 说明 |
|------|------|
| 多租户 | 租户间数据完全隔离 |
| 高可用 | 支持水平扩展 |
| 安全 | JWT + Spring Security + 数据加密 |
| 性能 | GIS查询 < 200ms，页面加载 < 2s |
| 移动端 | 响应式布局，后续考虑小程序 |

---

## 五、数据范围

### 村庄默认模板（可复制）

每个新村庄自动包含：

- 10 个 GIS 地标点位
- 4 类 IoT 设备配置
- 事件类型模板
- 产业分类模板

### 中堰村（默认演示村庄）

- 湖北省武汉市江夏区乌龙泉街道
- 面积：8.6 km²
- 人口：2156 人
- 产业：智慧大棚 / 荷虾混养 / 产业园
