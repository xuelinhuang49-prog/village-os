## Sprint 1: 用户·登录·多租户 (Week 1) ✅

### 目标
后端基础工程跑起来，登录认证 + 多租户框架就绪

### 后端
- [x] Spring Boot 3.2 工程搭建
- [x] MyBatis Plus + PostgreSQL 配置
- [x] JWT 生成/校验/刷新
- [x] Spring Security 集成
- [x] 用户登录接口 `POST /api/v1/auth/login`
- [x] 当前用户接口 `GET /api/v1/auth/me`
- [x] TenantContext (ThreadLocal)
- [x] JwtAuthenticationFilter (解析JWT → 设置租户上下文)
- [x] 村庄列表/详情/创建/切换
- [x] 中堰村种子数据

### 前端
- [ ] Vue3 + Vite 项目初始化
- [ ] Element Plus 安装
- [ ] 登录页面
- [ ] 路由 + Pinia 状态管理
- [ ] 村庄选择器

### 验收
```bash
curl -X POST :8080/api/v1/auth/login -d '{"username":"admin","password":"admin123"}'
# → JWT 包含 tenant_id + village_id
```

## 开发规范

### Git 分支策略
```
main          ← 生产分支
├── develop   ← 开发主分支
│   ├── sprint/1-user-auth
│   ├── sprint/2-dashboard
│   ├── sprint/3-gis
│   └── ...
```

### Commit 规范
```
feat: 新功能
fix: Bug修复
docs: 文档
refactor: 重构
test: 测试
```

### 每日站会（建议）
- 昨天做了什么
- 今天计划做什么
- 有什么阻塞

## 数据库版本管理

```
sql/
├── 00_master.sql       ← 入口
├── 01_init.sql         ← 建表 (V1.0)
├── ...
├── v1.1.sql            ← 迭代升级脚本
├── v1.2.sql
├── v2.0.sql
```

每次数据库变更必须新增版本号SQL文件。
