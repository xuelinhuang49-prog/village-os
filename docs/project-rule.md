# 蓝匠数智数字乡村平台 · 项目开发规则

## 一、模块冻结原则

已完成并确认的模块，**禁止随意修改 UI**。

当前已冻结模块：

| 模块 | 版本 | 核心文件 | 冻结日期 |
|------|------|----------|----------|
| 首页 | v1.0 | `HomePage.vue` | 2026-07 |
| 数字乡村驾驶舱 | v1.0 | `DashboardPage.vue` | 2026-07 |
| 数字产业中心 | v1.1 | `IndustryPage.vue` | 2026-07 |
| 病虫害智能预警 | v1.2 | `PestDashboard.vue` + `api/pest.js` | 2026-07 |
| 农产品电商 | v1.1 | `EcommercePage.vue` | 2026-07 |
| 数字服务中心 | v1.0 | `ServicePage.vue` | 2026-07 |
| 管理后台 | v1.0 | `AdminPage.vue` | 2026-07 |

**例外情况**（允许修改）：
- 严重 Bug
- 数据结构冲突
- 用户明确要求
- 公共安全漏洞

## 二、新功能通过接口连接

```
管理员后台 ──API──> 数据库 <──API── 前台展示
```

- 管理员增删改 → 通过 API
- 前台只读取数据 → 通过 API
- 禁止管理员端直接修改前台页面

## 三、模块独立维护

每个模块：
- 独立文件夹（`views/pest/`、`views/industry/`）
- 独立 API 模块（`api/pest.js`）
- 独立数据模型（`db/pest_module.sql`）
- 不同模块之间禁止交叉修改

## 四、开发顺序

```
模块1 完成 → 冻结 → 模块2 开发 → 冻结 → 模块3 开发 → ...
```

不允许：
- 改A → 改B → 回头改A
- 为统一样式去动已冻结模块

## 五、页面与数据分离

- 所有数据走 API 层，不写死在组件内
- 数据字段统一带：`villageId`、`landId`、`creatorId`、`status`
- 前端使用模拟数据开发，后端接口就绪后无缝切换

## 六、管理端后置

- 当前阶段只做村级展示端
- 管理后台(/admin) 等三个条件满足后再做：
  1. 知识库 >50条
  2. 村子配置自己的产业
  3. AI识别 >500次

## 七、版本管理

- 每完成一个模块打版本标签
- 版本号格式：v[主版本].[模块版本]
- 不允许跨版本修改已冻结模块
