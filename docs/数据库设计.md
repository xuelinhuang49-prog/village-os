## 表结构详细说明

### 1. tenant (租户表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| name | VARCHAR(100) | 租户名称 |
| code | VARCHAR(50) | 租户编码，唯一 |
| contact_person | VARCHAR(50) | 联系人 |
| contact_phone | VARCHAR(20) | 联系电话 |
| status | INT | 1=启用, 0=禁用 |
| create_time | TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | 更新时间 |

### 2. sys_user (系统用户表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| username | VARCHAR(50) | 用户名，唯一 |
| password | VARCHAR(200) | BCrypt加密密码 |
| real_name | VARCHAR(50) | 真实姓名 |
| phone | VARCHAR(20) | 手机号 |
| email | VARCHAR(100) | 邮箱 |
| tenant_id | BIGINT | 所属租户 |
| status | INT | 1=启用, 0=禁用 |

### 3. village (村庄表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| tenant_id | BIGINT | 所属租户 |
| name | VARCHAR(100) | 村庄名称 |
| code | VARCHAR(50) | 村庄编码 |
| province | VARCHAR(50) | 省 |
| city | VARCHAR(50) | 市 |
| district | VARCHAR(50) | 区/县 |
| address | VARCHAR(200) | 详细地址 |
| longitude | DOUBLE PRECISION | 经度 |
| latitude | DOUBLE PRECISION | 纬度 |
| area | DOUBLE PRECISION | 面积 (km²) |
| population | INT | 人口 |
| description | TEXT | 简介 |
| contact_person | VARCHAR(50) | 联系人 |
| contact_phone | VARCHAR(20) | 联系电话 |
| status | INT | 1=启用, 0=禁用 |

### 4. geo_object (GIS地理对象表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| tenant_id | BIGINT | 所属租户 |
| village_id | BIGINT | 所属村庄 |
| name | VARCHAR(100) | 点位名称 |
| type | VARCHAR(50) | 类型枚举 |
| longitude | DOUBLE PRECISION | 经度 |
| latitude | DOUBLE PRECISION | 纬度 |
| geometry | TEXT | WKT格式几何数据 |
| geom | GEOMETRY(POINT,4326) | PostGIS几何列 (自动生成) |
| status | INT | 1=启用 |
| extra_json | JSONB | 扩展信息 |
| deleted | INT | 逻辑删除 |

### 5. iot_device (IoT设备表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 (从1001开始) |
| tenant_id | BIGINT | 所属租户 |
| village_id | BIGINT | 所属村庄 |
| name | VARCHAR(100) | 设备名称 |
| device_type | VARCHAR(50) | greenhouse/weather_station/water_quality/smart_market |
| device_code | VARCHAR(100) | 设备编码 |
| device_status | VARCHAR(20) | normal/warning/alarm/offline |
| longitude | DOUBLE PRECISION | 经度 |
| latitude | DOUBLE PRECISION | 纬度 |
| location | VARCHAR(200) | 安装位置 |
| extra_json | JSONB | 传感器配置等 |

### 6. iot_data (IoT数据表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| tenant_id | BIGINT | 租户 |
| village_id | BIGINT | 村庄 |
| device_id | BIGINT | 设备ID |
| device_type | VARCHAR(50) | 设备类型 |
| data_json | JSONB | 传感器数据JSON |
| data_time | TIMESTAMP | 数据采集时间 |
| create_time | TIMESTAMP | 入库时间 |

**索引:** (device_id, data_time DESC), (village_id, data_time DESC)

### 7. event (事件表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| tenant_id | BIGINT | 租户 |
| village_id | BIGINT | 村庄 |
| title | VARCHAR(200) | 事件标题 |
| event_type | VARCHAR(50) | safety/environment/traffic/agriculture/complaint/other |
| level | VARCHAR(20) | normal/urgent/critical |
| event_status | VARCHAR(20) | pending/processing/completed/closed |
| description | TEXT | 描述 |
| location | VARCHAR(200) | 位置 |
| longitude | DOUBLE PRECISION | 经度 |
| latitude | DOUBLE PRECISION | 纬度 |
| reporter_id | BIGINT | 上报人 |
| handler_id | BIGINT | 处理人 |
| extra_json | JSONB | 扩展信息 |

---

## PostGIS 兼容说明

- 默认使用 TEXT 存储几何数据 (WKT 格式)
- 检测到 PostGIS 扩展后自动添加 `geom GEOMETRY(POINT, 4326)` 列
- PostGIS 启用后自动创建 GIST 空间索引
- 手动启用: `CREATE EXTENSION postgis;`
