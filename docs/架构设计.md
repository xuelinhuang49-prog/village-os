## 三、多租户架构

```
请求 → JwtFilter (解析JWT) → TenantContext (ThreadLocal)
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              tenant_id       village_id        user_id
                    
所有SQL自动带租户条件，实现数据隔离
```

## 四、认证流程

```
1. POST /api/v1/auth/login {username, password}
2. 后端验证 → 生成 JWT (含 user_id, tenant_id, village_id)
3. 前端存储 Token → 每次请求带 Authorization: Bearer <token>
4. JwtFilter 解析 → 设置 TenantContext → 放行
5. GET /api/v1/auth/me → 获取当前用户信息
```

## 五、WebSocket 实时推送

```
Client ──► ws://host:8080/ws/iot ──► IotWebSocketHandler
                                          │
                                    IotSimulatorService
                                    每5秒推送一次模拟数据
                                          │
                                    broadcast(json)
                                          │
                                   所有已连接客户端
```
